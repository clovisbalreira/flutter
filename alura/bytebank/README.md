# ByteBank

📌 **Descrição**

Aplicativo bancário completo desenvolvido em Flutter durante os cursos do Alura. Permite gerenciar contas, transferências e visualizar o histórico de transações com uma interface intuitiva.

---

## 🚀 Tecnologias

- Flutter
- Dart
- SQLite (persistência local)
- Provider (gerenciamento de estado)

---

## 🎯 Funcionalidades

- Criar e gerenciar contas bancárias
- Realizar transferências entre contas
- Visualizar histórico de transações
- Listar contatos para transferência
- Persistência de dados local

## ▶️ Como Rodar

1. **Clone o repositório**
   ```bash
   cd alura/bytebank
   ```

2. **Instale as dependências**
   ```bash
   flutter pub get
   ```

3. **Execute o aplicativo**
   ```bash
   flutter run
   ```
