# TechTaste

📌 **Descrição**

Plataforma de compartilhamento de receitas e dicas culinárias desenvolvida em Flutter. Permite aos usuários criar perfil, compartilhar receitas, seguir outros usuários e descobrir novas receitas da comunidade.

---

## 🚀 Tecnologias

- Flutter
- Dart
- Firebase (autenticação e armazenamento)
- Cloud Firestore (banco de dados em tempo real)
- Provider (gerenciamento de estado)
- Image Picker (upload de imagens)

---

## 🎯 Funcionalidades

- Autenticação com Firebase
- Criar e compartilhar receitas
- Sistema de curtidas e comentários
- Seguir outros usuários
- Feed de receitas em tempo real
- Perfil de usuário personalizável
- Busca e filtros avançados

## ▶️ Como Rodar

1. **Clone o repositório**
   ```bash
   cd alura/techtaste
   ```

2. **Instale as dependências**
   ```bash
   flutter pub get
   ```

3. **Configure o Firebase**
   - Crie um projeto no Firebase Console
   - Configure credenciais em `android/` e `ios/` conforme a documentação

4. **Execute o aplicativo**
   ```bash
   flutter run
   ```
