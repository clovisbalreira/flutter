# ByteBank API

📌 **Descrição**

Extensão do projeto ByteBank que integra requisições HTTP para comunicação com uma API REST. Aprenda como consumir APIs e trabalhar com autenticação básica em Flutter.

---

## 🚀 Tecnologias

- Flutter
- Dart
- HTTP (requisições de API)
- Provider (gerenciamento de estado)
- JSON (serialização de dados)

---

## 🎯 Funcionalidades

- Consumir dados de API REST
- Requisições GET, POST e DELETE
- Manipulação de JSON
- Tratamento de erros HTTP
- Cache de dados em memória

---

## ▶️ Como Rodar

1. **Clone o repositório**
   ```bash
   cd alura/bytebankapi
   ```

2. **Instale as dependências**
   ```bash
   flutter pub get
   ```

3. **Configure a URL da API** (em lib/main.dart ou arquivo de config)

4. **Execute o aplicativo**
   ```bash
   flutter run
   ```
