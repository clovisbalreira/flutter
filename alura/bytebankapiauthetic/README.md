# ByteBank API Autenticação

📌 **Descrição**

Evolução do projeto ByteBank API implementando autenticação JWT e autorização. Aprenda como gerenciar tokens, fazer login seguro e manter sessões de usuário.

---

## 🚀 Tecnologias

- Flutter
- Dart
- HTTP (requisições de API)
- JWT (autenticação)
- SharedPreferences (armazenamento seguro de tokens)
- Provider (gerenciamento de estado)

---

## 🎯 Funcionalidades

- Tela de login com validação
- Autenticação com JWT
- Armazenamento seguro de tokens
- Requisições autenticadas
- Logout e limpeza de sessão
- Tratamento de token expirado

## ▶️ Como Rodar

1. **Clone o repositório**
   ```bash
   cd alura/bytebankapiauthetic
   ```

2. **Instale as dependências**
   ```bash
   flutter pub get
   ```

3. **Configure as credenciais de teste** (em arquivo de config)

4. **Execute o aplicativo**
   ```bash
   flutter run
   ```
