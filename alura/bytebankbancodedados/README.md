# ByteBank Banco de Dados

📌 **Descrição**

Projeto que aprofunda o uso de persistência de dados em Flutter, implementando um banco de dados local completo com SQLite. Gerencia contas, transações e dados de forma persistente.

---

## 🚀 Tecnologias

- Flutter
- Dart
- SQLite (banco de dados local)
- SQFlite (driver SQLite para Flutter)
- Provider (gerenciamento de estado)

---

## 🎯 Funcionalidades

- Criar tabelas no banco de dados
- Inserir, atualizar e deletar dados
- Consultas complexas ao banco
- Migração e versionamento de schema
- Transações seguras
- Sincronização com API
