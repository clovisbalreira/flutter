# Vakinha Burger Mobile

📌 **Descrição**

Aplicativo de delivery de hambúrgueres desenvolvido em Flutter. Permite aos usuários navegar pelo cardápio, adicionar itens ao carrinho, acompanhar pedidos e realizar pagamentos de forma segura.

---

## 🚀 Tecnologias

- Flutter
- Dart
- Firebase (autenticação e banco de dados)
- Stripe / PayPal (pagamentos)
- Provider (gerenciamento de estado)
- Image Picker (upload de imagens)
- Google Maps (localização)

---

## 🎯 Funcionalidades

- Catálogo completo de hambúrgueres
- Carrinho de compras com cálculo de total
- Customização de pedidos
- Sistema de cupons de desconto
- Rastreamento de pedidos em tempo real
- Histórico de pedidos
- Múltiplas formas de pagamento
- Localização e endereço de entrega

## ▶️ Como Rodar

1. **Clone o repositório**
   ```bash
   cd pessoal/vakinha_burger-mobile
   ```

2. **Configure as credenciais**
   - Firebase
   - Stripe ou PayPal (se implementado)
   - Google Maps API (se implementado)

3. **Instale as dependências**
   ```bash
   flutter pub get
   ```

4. **Execute o aplicativo**
   ```bash
   flutter run
   ```
