# Cartão Flutter

📌 **Descrição**

Projeto de design e UI focado em criar uma interface minimalista e elegante de um cartão digital. Demonstra animações suaves, transições e boas práticas de design em Flutter.

---

## 🚀 Tecnologias

- Flutter
- Dart
- Animações (Animation Controller)
- Gestos e interatividade

---

## 🎯 Funcionalidades

- Exibição de cartão digital animado
- Efeito de flip no cartão
- Animações suaves de transição
- Design responsivo
- Visualização de dados do cartão
- Interatividade com gestos
