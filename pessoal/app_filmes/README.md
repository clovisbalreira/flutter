# App Filmes

📌 **Descrição**

Aplicativo mobile para explorar, buscar e gerenciar filmes. Integrado com API de filmes, permite aos usuários visualizar informações detalhadas, ratings, elenco e adicionar filmes à sua watchlist pessoal.

---

## 🚀 Tecnologias

- Flutter
- Dart
- The Movie Database API (TMDB)
- HTTP (requisições de API)
- Provider (gerenciamento de estado)
- SharedPreferences (armazenamento local)

---

## 🎯 Funcionalidades

- Listar filmes populares em tempo real
- Buscar filmes por título
- Visualizar detalhes completos do filme
- Ver elenco e equipe técnica
- Adicionar filmes à watchlist
- Classificação pessoal de filmes
- Sistema de favoritos

## ▶️ Como Rodar

1. **Clone o repositório**
   ```bash
   cd pessoal/app_filmes
   ```

2. **Obtenha uma chave de API**
   - Cadastre-se em [The Movie Database (TMDB)](https://www.themoviedb.org)
   - Gere sua chave de API

3. **Configure a chave de API** (em um arquivo .env ou config)

4. **Instale as dependências**
   ```bash
   flutter pub get
   ```

5. **Execute o aplicativo**
   ```bash
   flutter run
   ```
