# Pokemon

📌 **Descrição**

Explorador interativo de Pokémon desenvolvido em Flutter. Busque Pokémon, visualize informações detalhadas, estatísticas, tipos e evoluções através de uma API pública de Pokémon.

---

## 🚀 Tecnologias

- Flutter
- Dart
- PokéAPI (API gratuita de Pokémon)
- HTTP (requisições de API)
- Cache de imagens
- Provider (gerenciamento de estado)

---

## 🎯 Funcionalidades

- Listar Pokémon da PokéAPI
- Buscar Pokémon por nome ou ID
- Visualizar detalhes completos
- Exibir estatísticas (HP, Ataque, Defesa, etc)
- Ver tipos e enfraquecimentos
- Galeria de imagens do Pokémon
- Sistema de favoritos (offline)
