# Repositório de Projetos Flutter

📌 **Descrição**

Repositório com projetos e exercícios desenvolvidos em **Flutter** durante a jornada de aprendizado. Inclui projetos de cursos do Alura e projetos pessoais, com foco em boas práticas de desenvolvimento mobile.

---

## 🧠 Conteúdo

### 📚 Projetos Alura
- **bytebank** - Aplicativo bancário com gerenciamento de transações
- **bytebankapi** - Integração do ByteBank com API REST
- **bytebankapiauthetic** - Implementação de autenticação na API do ByteBank
- **bytebankbancodedados** - Persistência de dados com banco de dados local
- **cozinhando_casa** - Aplicativo de receitas
- **techtaste** - Plataforma de compartilhamento de receitas e dicas culinárias
- **database** - Estudos e testes com banco de dados

### 👤 Projetos Pessoais
- **app_filmes** - Aplicativo para explorar e gerenciar filmes
- **cartaoFlutter** - Cartão de crédito (UI/UX)
- **Pokemon** - Explorador de Pokémon com integração de API
- **vakinha_burger-mobile** - App de delivery de hambúrguer

## ⚙️ Requisitos

Antes de começar, certifique-se de ter instalado:

- **Flutter SDK** (versão 3.0+)
- **Dart** (incluído no Flutter)
- **Android Studio** ou **Xcode** (para emular)

Instale o Flutter: [flutter.dev](https://flutter.dev)

---

## ▶️ Como Rodar

### 1. Navegue até a pasta do projeto
```bash
cd alura/bytebank
# ou
cd pessoal/app_filmes
```

### 2. Instale as dependências
```bash
flutter pub get
```

### 3. Execute o aplicativo
```bash
flutter run
```

### 4. (Opcional) Rode em modo release
```bash
flutter run --release
```
